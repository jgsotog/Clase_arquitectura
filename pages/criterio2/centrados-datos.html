Tema 2.2

Estilos Centrados en Datos

Los estilos centrados en datos se caracterizan por tener un almacen de datos central (repositorio) al que acceden multiples componentes independientes. La comunicacion entre componentes se realiza a traves de los datos compartidos, no mediante llamadas directas entre ellos.

Variantes Principales

Existen dos variantes principales de arquitecturas centradas en datos, que se diferencian en como se activa el procesamiento de los datos.

Estilo Repositorio

En el estilo repositorio, los clientes (componentes) acceden al almacen de datos de forma activa. Cada cliente decide cuando leer o escribir datos. El repositorio es pasivo: solo almacena informacion y responde a solicitudes.

Ejemplo clasico

Un sistema de base de datos relacional donde multiples aplicaciones (clientes) consultan y modifican los datos. La base de datos no inicia comunicacion; solo responde a las solicitudes de los clientes.

Estilo Pizarron (Blackboard)

En el estilo pizarron, el almacen de datos tiene un rol activo. Cuando los datos cambian, el pizarron notifica a los componentes interesados. Los componentes se activan en respuesta a cambios en los datos, no por decision propia.

Ejemplo clasico

Sistemas de inteligencia artificial donde multiples agentes de conocimiento observan un espacio compartido. Cuando un agente modifica datos, otros agentes se activan automaticamente si los datos son relevantes para ellos.

Control del flujo Los clientes deciden cuando acceder El pizarron notifica a los clientes
Almacen de datos Pasivo Activo
