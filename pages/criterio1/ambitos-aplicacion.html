Tema 1.5

Ambitos de Aplicacion

La arquitectura de software se adapta al dominio donde se aplica. Sistemas web, moviles, embebidos, de inteligencia artificial o de videojuegos requieren enfoques arquitectonicos distintos. Cada ambito tiene sus propias restricciones, patrones preferidos y prioridades.

1. Sistemas Web y Comercio Electronico

Caracteristicas del ambito

Alta concurrencia de usuarios, necesidad de escalabilidad horizontal, disponibilidad 24/7, seguridad transaccional. Arquitecturas tipicas: Cliente-Servidor, Microservicios, Capas (MVC/MVP/MVVM).

Capa / Servicio Tecnologia Comun Responsabilidad
Frontend (SPA) React, Angular, Vue Interfaz de usuario, interaccion
API Gateway Kong, Nginx, AWS API GW Enrutamiento, autenticacion, rate limiting
Servicio Catalogo Node.js, Spring Boot Productos, busqueda, categorias
Servicio Pagos Java, Go Transacciones, PCI compliance
Servicio Envios Python, Node.js Logistica, tracking
Base de Datos PostgreSQL + Redis (cache) Persistencia y rendimiento
Cola de Mensajes RabbitMQ, Kafka Comunicacion asincrona entre servicios

2. Aplicaciones Moviles

Caracteristicas del ambito

Recursos limitados (bateria, memoria, procesador), conectividad intermitente, necesidad de funcionar offline, multiples resoluciones de pantalla. Arquitecturas tipicas: MVVM, Clean Architecture, MVP con capas.

3. Sistemas Embebidos e IoT

Caracteristicas del ambito

Restricciones severas de hardware (memoria, procesador), requisitos de tiempo real, alta confiabilidad, interaccion con sensores y actuadores. Arquitecturas tipicas: Basadas en Eventos, Pipeline, Superloop, RTOS con tareas.

4. Sistemas Empresariales (ERP, CRM)

Caracteristicas del ambito

Procesos de negocio complejos, multiples roles de usuario, integracion con sistemas legados, transacciones criticas, regulaciones y compliance. Arquitecturas tipicas: Capas (N-Tier), SOA (Service-Oriented Architecture), CQRS.

Modulo ERP Estilo Arquitectonico Razon
Contabilidad Capas + Event Sourcing Auditoria completa, trazabilidad de transacciones
Inventario CQRS Lecturas frecuentes (consultas), escrituras criticas (movimientos)
Recursos Humanos Capas (MVC) CRUD intensivo, formularios complejos, reportes
Ventas Microservicios Alta variabilidad, multiples canales (web, movil, tienda)
Integracion SOA / ESB Conectar sistemas heterogeneos y legados

5. Videojuegos

Caracteristicas del ambito

Rendimiento critico (60 FPS), gestion eficiente de memoria, fisica en tiempo real, renderizado 3D, multijugador en red. Arquitecturas tipicas: ECS (Entity-Component-System), Game Loop, Scene Graph.

Resumen: Arquitectura por Ambito

Ambito Prioridad #1 Estilo Preferido Tecnologias Clave
Web / E-Commerce Escalabilidad, Disponibilidad Microservicios, Capas React, Node, Docker, Kubernetes
Movil Offline-first, UX fluida Clean Architecture, MVVM Swift, Kotlin, Flutter, SQLite
IoT / Embebidos Tiempo real, Confiabilidad Event-Driven, Pipeline C/C++, MQTT, Edge Computing
Empresarial (ERP) Integracion, Compliance SOA, Capas, CQRS Java EE, .NET, SAP, Oracle
Videojuegos Rendimiento (60 FPS) ECS, Game Loop C++, Unity (C#), Unreal
IA / Machine Learning Procesamiento de datos Pipeline, Microservicios Python, TensorFlow, MLflow
