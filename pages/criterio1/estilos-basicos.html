Estilos Arquitectonicos Basicos

Un estilo arquitectonico define un conjunto de restricciones sobre la forma en que se organizan los componentes y como interactuan. Cada estilo resuelve un tipo de problema recurrente y tiene ventajas y limitaciones especificas.

1. Estilo Monolitico

Definicion

Todo el sistema se despliega como una sola unidad. Todos los modulos comparten el mismo proceso, memoria y base de datos. Es el estilo mas simple y comun para aplicaciones pequenas y medianas.

2. Estilo Cliente-Servidor

Definicion

Separa el sistema en dos roles: el cliente (que solicita servicios) y el servidor (que los provee). La comunicacion es tipicamente via red usando protocolos como HTTP. Es el fundamento de la web.

3. Estilo de Microservicios

Definicion

Descompone el sistema en servicios pequenos, autonomos e independientemente desplegables. Cada microservicio tiene su propia base de datos y se comunica con los demas a traves de APIs o mensajes.

4. Estilo Basado en Eventos

Definicion

Los componentes se comunican emitiendo y escuchando eventos. Ningun componente necesita conocer directamente a los demas. Un bus de eventos central o distribuido gestiona la entrega de los mensajes.
